# 画像格納場所

X投稿用の**公開可能なオリジナル画像**のみ保存します。

- 推奨ファイル名：`YYYY/MM/<post_id>.png`（例：`2026/10/my-post-id.png`）
- 公開直リンク：`https://raw.githubusercontent.com/N-GitJP/igai-gazou-koukai/main/images/YYYY/MM/<post_id>.png`
- 対応：PNG / JPG / WebP、1画像5MiB以内
- 予約後は画像を削除・差し替えしない
- GitHub Pages、Actions、公開用トークンは使用しない

このREADME自体は投稿用画像ではなく、Bufferへの送信対象ではありません。
